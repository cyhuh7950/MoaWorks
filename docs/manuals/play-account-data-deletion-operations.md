# MoaWorks Mobile 계정·데이터 삭제 요청 운영 절차

## 적용 범위

- 공개 안내: `https://moaworks.sinsan.kr/privacy/#deletion-request`
- 운영자: sinsan
- 접수처: `helpdesk@moaworks.sinsan.kr` 또는 관리자에게 직접 요청
- 처리 기준: 접수 후 30일 이내에 처리 결과를 회신한다. 업무 인계나 법령상 보존 등으로 삭제할 수 없는 자료는 같은 기간 안에 사유, 자료 범위, 적용 보관 기간 또는 기간을 정하는 기준을 개별 안내한다.

계정 삭제와 업무 자료의 물리 삭제는 별개다. 현재 관리자 사용자 삭제는 `users`와 `mail_accounts`의 상태를 `deleted`로 변경한다. 이 동작만으로 메일, 결재, 메신저, 파일, 일정, 주소록, 감사 기록 또는 백업이 모두 지워졌다고 안내하지 않는다.

## 접수와 처리

1. 요청일, 요청 계정 이메일, 회사·조직명, 요청 범위를 관리 가능한 업무 기록에 남긴다. 접수 사실과 처리 기준을 회신한다. 이메일로 비밀번호, 주민등록번호 또는 API 키를 요구하지 않는다.
2. 계정 정보와 소속 조직을 확인하고, 별도 안전한 경로로 요청자의 본인 여부 및 요청 권한을 확인한다. 타인의 계정이나 조직 자료 삭제는 권한이 확인되기 전까지 실행하지 않는다.
3. 관리자와 관련 업무 담당자에게 인계가 필요한 메일, 결재, 메신저, 파일, 일정 및 주소록 자료가 있는지 확인한다. 법령·분쟁·보안·감사·조직 정책에 따른 보존 필요성과 백업·연동 기록의 범위를 함께 검토한다.
4. 삭제할 수 있는 범위와 보존할 범위를 구분하여 승인된 관리자 절차로 처리한다. 계정 접근 차단과 자료의 실제 삭제 여부를 각각 확인한다. 자료별 삭제 기능이나 보존 기한이 확인되지 않으면 수행한 것으로 기록하지 않는다.
5. 접수 후 30일 이내에 요청자에게 처리 결과를 회신한다. 삭제된 범위, 남는 자료의 종류, 보존 사유, 적용 기간 또는 기간을 정하는 기준, 추가 문의 경로를 구분해서 알린다. 아직 끝나지 않은 법적·업무 절차가 있으면 그 상태와 후속 조치를 명시한다.

## 보관 기간 확인

- 일반 메일의 회사별 보관 설정은 30일, 90일, 180일, 365일 또는 자동 만료 없음이다. 요청 대상의 **실제 설정값**을 확인해 회신한다. 스팸함·휴지통 등 별도 정책이 있는 항목에 일반 메일 설정을 그대로 적용하지 않는다.
- 결재·메신저·파일·일정·주소록·감사 기록·백업에는 계정 삭제와 함께 적용되는 공통 만료 기간이 없다. 각 자료의 업무·보안·법령·조직 정책상 사유와 실제 보존 기준을 확인한다.
- 확인되지 않은 보존 기간을 임의의 날짜로 약속하거나, `deleted` 상태 변경을 물리 삭제로 표현하지 않는다.

## 종료 기록

접수일, 본인 확인 결과, 인계·보존 판단, 실제 실행한 관리자 조치, 확인된 자료별 결과, 요청자 회신일과 후속 담당자를 기록한다. 기록에는 비밀번호나 다른 비밀값을 넣지 않는다. 공개 안내 문안과 실제 운영 절차가 달라지면 Play Console의 데이터 삭제 URL 안내도 함께 재검토한다.

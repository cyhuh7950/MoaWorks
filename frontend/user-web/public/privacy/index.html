MoaWorks Mobile 개인정보처리방침

운영자: sinsan
시행일: 2026년 9월 28일

sinsan은 MoaWorks Mobile 및 연결된 MoaWorks 업무 서비스를 제공하면서 필요한 개인정보를 다음과 같이 처리합니다. 이 방침은 계정으로 로그인하여 메일, 결재, 메신저, 일정, 파일, 주소록, 개인 AI 기능을 이용하는 경우에 적용됩니다.

MoaWorks Mobile 계정 및 데이터 삭제 요청 방법 바로가기

1. 처리하는 정보와 목적

  • 계정과 인증: 아이디, 이름, 업무용 이메일 주소, 소속·역할, 로그인 및 접속 기록을 계정 확인, 접근 권한 관리, 보안 점검에 사용합니다. 비밀번호는 인증 과정에 사용합니다.
  • 업무 기능: 메일의 주소·제목·본문·첨부파일, 결재 문서와 처리 기록, 메신저 대화와 파일, 일정, 주소록·조직도 정보 및 파일 자료를 해당 업무 기능의 제공·검색·보관에 사용합니다.
  • 개인 AI 및 번역: 사용자가 입력한 프롬프트, 최근 대화 맥락, 번역 원문과 결과, 선택한 설정을 요청 처리와 응답 제공에 사용합니다. 개인 AI 연결을 위해 사용자가 설정한 Provider 정보와 API 키가 처리될 수 있습니다.
  • 서비스 운영: 오류 및 보안 관련 기록을 장애 대응과 부정 이용 방지에 사용합니다.

앱에는 자체 회원가입 화면이 없습니다. 계정의 생성·삭제와 권한 부여는 관리자가 수행합니다.

2. 처리와 외부 전송

업무 자료는 MoaWorks 서비스 서버를 통해 처리됩니다. 사용자가 개인 AI나 번역 기능을 이용하면 프롬프트, 필요한 최근 대화 내용 또는 번역 원문이 서비스 서버를 거쳐 설정된 외부 AI·번역 Provider로 전달될 수 있습니다. 전달 범위는 사용한 기능과 설정에 따라 달라집니다. 해당 기능을 사용하지 않으면 그 요청 내용은 Provider로 전송되지 않습니다.

메일 발송 등 사용자가 요청한 업무 처리를 위해 필요한 정보는 지정한 수신자 및 연결된 서비스로 전달될 수 있습니다.

3. 보관과 삭제

정보는 서비스 제공과 운영에 필요한 동안 보관하며, 삭제 요청 시 본인 확인과 업무 자료 인계·보존 필요성을 검토하여 처리합니다. 계정 삭제는 우선 사용자 계정과 메일 계정의 상태를 삭제로 변경하며, 업무 자료를 즉시 모두 물리적으로 지우지는 않습니다.

일반 메일은 회사의 보관 설정에 따라 30일, 90일, 180일, 365일 또는 자동 만료 없음으로 관리됩니다. 결재, 메신저, 파일, 일정, 주소록, 감사 기록과 백업은 업무·보안·법령·조직 정책에 따라 계정 삭제 후에도 보관될 수 있으며, 모든 자료에 공통으로 적용되는 만료 기간은 없습니다. 삭제할 수 없는 자료의 사유와 범위, 적용 보관 기간 또는 기간을 정하는 기준은 요청별로 확인해 안내합니다.

4. 안전한 처리

계정별 접근 권한을 적용하고, 서비스 운영에 필요한 범위로 접근을 제한하며, 전송 구간 보호와 보안 점검을 수행합니다. 사용자는 계정 비밀번호와 개인 AI Provider의 API 키가 타인에게 노출되지 않도록 관리해 주세요.

5. 이용자 문의와 권리 행사

본인 정보의 열람, 정정, 삭제, 처리 관련 문의는 관리자 또는 helpdesk@moaworks.sinsan.kr로 보내 주세요. MoaWorks Mobile 계정과 데이터 삭제 요청 절차는 아래에서 확인할 수 있습니다.

6. MoaWorks Mobile 계정 및 데이터 삭제 요청

운영자 sinsan은 로그인하지 않은 이용자의 요청도 helpdesk@moaworks.sinsan.kr로 이메일 보내기를 통해 접수합니다. 앱에서 계정을 만들 수 없으며, 관리자에게도 계정 삭제를 요청할 수 있습니다.

  1. 이메일에 계정 이메일 주소, 회사·조직명, 삭제를 원하는 계정 또는 데이터의 범위를 적어 보내 주세요. 비밀번호나 주민등록번호는 보내지 마세요.
  2. HelpDesk가 안전한 방법으로 본인 여부를 확인하고, 필요한 업무 자료의 인계 및 보존 사유를 검토합니다.
  3. 요청 접수 후 30일 이내에 처리 결과를 회신합니다. 법령상 보관 또는 업무 인계로 삭제할 수 없는 항목은 같은 기간 안에 사유, 자료 범위, 적용 보관 기간 또는 기간을 정하는 기준을 개별 안내합니다.

계정 삭제 시 계정과 연결된 메일 계정의 상태를 삭제로 바꿉니다. 요청 범위에서 삭제 가능한 개인정보는 확인 후 처리하지만, 메일·결재·메신저·파일·일정·주소록·감사 기록·백업의 업무 자료가 동시에 모두 삭제되는 것은 아닙니다. 일반 메일은 회사 설정에 따라 30·90·180·365일 또는 자동 만료 없이 보관될 수 있으며, 다른 자료의 구체적인 보관 기간은 해당 업무와 보존 사유에 따라 달라집니다. 요청별 결과에 남는 자료와 보관 기준을 안내합니다.

7. 방침 변경

처리 내용이 변경되면 이 페이지에 변경 사항과 적용일을 안내합니다. 개인정보 관련 문의는 위 이메일로 보내 주세요.
